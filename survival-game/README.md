# STILL ALIVE, PROBABLY

奇妙な世界で目を覚ました少女が、
マップを探索し、資源を集め、拠点を発展させながら脱出を目指す、
小さなサバイバル探索ゲームです。

## PLAY

GitHub Pages でプレイできます。

* `survival-game/index.html` … ゲーム本体
* `survival-game/about.html` … ゲーム説明 / ABOUT

## GAME

この世界を生き抜いて、脱出することが目的です。

探索すると木材・石材・食糧などの資源を手に入れることができます。

ただし、探索するたびに1日が経過し、空腹度が減少します。
危険な場所ではライフが減ることもあります。

食糧を使えば空腹度を回復できます。

集めた資源を使って施設や装備を作り、
少しずつ拠点を発展させていきます。

そして世界のどこかには、
ここから出るための手がかりがあるかもしれません。

## BASIC RULES

* 探索すると1日経過します
* 探索によって空腹度が減少します
* 地形によってはライフが減少します
* 食糧を1消費すると空腹度を回復できます
* 食堂を強化すると食事の回復量が増えます
* 探索で集めた資源を使って施設や装備を作れます
* ライフが0になるとゲームオーバーです
* 空腹状態が続くとライフも減少します

## WORLD

フィールドは六角形のマスで構成されています。

探索を進めることで、草原・森・岩場・池・洞窟などの地形を発見できます。

世界には通常の資源だけでなく、
奇妙な食材や特殊なアイテムも存在します。

何があるかは、実際に探してみてください。

## FOOD COLLECTION

探索中に見つけた奇妙な食材は、図鑑に登録されます。

食材は単なる資源とは別に、
発見そのものを楽しむコレクション要素になっています。
